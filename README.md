# 三十六计 · 技能五子棋

> 五子棋遇上三十六计，当棋盘上的博弈变成兵法谋略的较量。

双击打开 `gomoku.html` 即可开战，无需安装任何依赖。

## 玩法

- **15×15 棋盘**，无禁手，先连成五子获胜（幻想子计入连珠，中立棋子不计入）
- **技能池**：每局从三十六计中随机抽取 6-10 个，双方共用
- **能量**：每落一子 +1，上限 10；使用计策消耗能量
- **共享冷却**：计策用后进入冷却，双方都不能用；每过一个回合（任意一方）冷却 -1
- **回合**：每回合必须落一子；回合内可先使用计策再落子，"落子类"计策本身就算这一手
- **取消**：选中计策后再点一次、按 Esc 或右键即可取消；二段选择中途取消会返还能量和冷却
- **悔棋**：回到本回合开始；本回合还没操作时回到上一回合开始（人机对战会一直退回到玩家回合）
- **AI 对手**：AI 执白、玩家执黑。AI 会在回合开头推演本局技能池里的计策，比直接落子明显更好时先用一次计策再落子（例如对方活四堵不住时趁火打劫、只差一步时连环计、能量不够时打草惊蛇），并遵守能量、共享冷却、封印和落子限制
- **测试模式**：全部 36 计可用、能量无限、无冷却，方便体验每个计策

## 开发

纯浏览器脚本，无构建步骤。`js/` 下的文件按依赖顺序用普通 `<script>` 加载，共享全局作用域：

| 文件 | 内容 |
|------|------|
| `js/board.js` | 棋盘常量与通用工具函数 |
| `js/skills.js` | 三十六计技能定义（每个技能一个对象） |
| `js/game.js` | 游戏核心：状态、落子规则、回合流程、悔棋（不依赖 DOM） |
| `js/ai.js` | AI：棋型查表 + VCF 算杀 + alpha-beta 搜索；计策推演 |
| `js/view.js` | 界面渲染 |
| `js/main.js` | 启动、按钮与键盘、AI 调度（一步一步执行，直到 AI 回合结束） |
| `css/gomoku.css` | 样式 |

**新增或修改计策**：在 `js/skills.js` 的 `SKILLS` 数组中编辑对应对象。`use()` 只需修改状态并返回 `true`，失败时 `return g.fail('原因')`，游戏会自动回滚；需要第二次点选的计策再提供 `pendingTargets()` 与 `resolve()`。文件开头有完整说明。

**测试**（需要 Node.js 18+，无第三方依赖）：

```bash
npm test
```

仅供娱乐和学习目的，基于浏览器技术开发，无需后端服务。
