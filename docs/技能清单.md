# 技能五子棋 - 技能清单

> 本文档仅用于记录当前技能，供修改后向AI下达指令使用。表格与 `js/skills.js` 保持一致。

---

## 基础规则

- 能量：每落子+1，上限10
- 技能共享：双方共用技能池，CD公用（每个回合结束时 -1）
- 每局随机：6-10个技能
- 每回合必须落一子；"落子类"技能（笑里藏刀、抛砖引玉、假途伐虢、指桑骂槐）本身算作这一手
